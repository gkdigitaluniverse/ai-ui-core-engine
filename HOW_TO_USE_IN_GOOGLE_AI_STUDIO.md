# How to Use in Google AI Studio

1. Download or bundle repository as ZIP:
   zip -r ai-ui-core-engine.zip web-tokens/ android-m3/ motion-3d/ api-catalog/
2. Open Google AI Studio (aistudio.google.com).
3. Select Gemini 1.5 Pro or Gemini 2.0 Flash.
4. Upload `ai-ui-core-engine.zip` using the (+) Add File button.
5. Paste contents of `google-ai-studio-prompt.md` into System Instructions.
6. Start prompting to build production-grade web and mobile apps.
