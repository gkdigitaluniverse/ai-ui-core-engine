# ⚡ ai-ui-core-engine

> Production-grade design tokens, animation contracts, and UI architecture distilled from 10k+ star repos to force LLMs into building VC-level apps.

## Architecture
- `web-tokens/`: Shadcn v4 tokens, button and card component contracts.
- `android-m3/`: Google NowInAndroid Material 3 tokens.
- `motion-3d/`: 2D Lottie vectors, spring physics, and 3D Canvas specs.
- `api-catalog/`: 2500+ curated free public API endpoints.
- `google-ai-studio-prompt.md`: Master system instructions for LLMs.
